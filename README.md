# Shieldline: Insurance Policy & Claims Management

Flask + SQLite app covering Auto, Health, Life, Home, Travel and Commercial lines.

## Run
    python -m venv venv
    venv\Scripts\activate        (Windows)   |   source venv/bin/activate   (macOS/Linux)
    pip install -r requirements.txt
    python app.py
Open http://127.0.0.1:5000 and sign in with **admin / admin123**.

The database (insurance.db) is created with sample data on first run. Delete it to reset.
